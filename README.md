# Agentic AI Zero to Hero

A free course that takes you from zero to production-ready Agentic AI. Over the series we build **TripPilot**, an AI travel assistant, one feature per lesson.

- **Who it's for:** students, freshers, developers, and anyone curious about Agentic AI
- **You need:** basic Python (lesson 5 onward). No AI experience
- **Cost:** free. Every demo runs on a free model
- **Videos:** [Full course playlist](https://www.youtube.com/playlist?list=PLExTFh0CQIwU) · [YouTube: Pavan Elthepu](https://www.youtube.com/@PavanElthepu)

## How to use this repo

1. Watch the lesson video.
2. Open the lesson folder and read the notes and the cheat sheet.
3. From lesson 5 on, run the code and do the exercise.
4. Stuck? Ask in [Discussions](../../discussions).

If this course helps you, star the repo so others can find it.
