# Agentic AI Zero to Hero

A free course that takes you from zero to production-ready Agentic AI. Over the series we build **TripPilot**, an AI travel assistant, one feature per lesson.

- **Who it's for:** students, freshers, developers, and anyone curious about Agentic AI
- **You need:** basic Python (lesson 3 onward). No AI experience
- **Cost:** free. Every demo runs on a free model
- **Videos:** [YouTube: Pavan Elthepu](https://www.youtube.com/@PavanElthepu)

## Lessons

| # | Lesson | What you get |
|---|---|---|
| 1 | [What Is Agentic AI? 70 Years of AI, Explained Simply](lessons/01-what-is-agentic-ai) | Cheat sheet, slides, quiz |
| 2 | [Generative AI vs AI Agents vs Agentic AI](lessons/02-genai-vs-ai-agents-vs-agentic-ai) | Cheat sheet, slides, quiz |
| 3 | [How Agentic AI Works: build the agent loop in Python](lessons/03-how-agentic-ai-works) | **First code:** TripPilot v0 |
| 4 | How LLMs Work: tokens, context, temperature | Code: call an LLM, count tokens |
| 5 | Choosing a Model: free vs paid, local vs API | Code: one prompt, 3 models |
| 6 | Agentic AI Architecture: planning, memory, tools, guardrails | Code: split TripPilot into parts |
| 7 | LangChain v1: rebuild TripPilot with `create_agent` | Code |
| 8 | Messages, Chat Models and Streaming | Code |

Lessons 4-8 are coming soon. Each lesson folder has notes, a 1-page cheat sheet, slides, a short quiz, and (from lesson 3) the code.

## How to use this repo

1. Watch the lesson video.
2. Open the lesson folder and read the notes and the cheat sheet.
3. From lesson 3 on, run the code and do the exercise.
4. Stuck? Ask in [Discussions](../../discussions).

If this course helps you, star the repo so others can find it.
